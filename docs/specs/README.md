# Specs

Designs for work that is decided in principle but not built yet. One file
per topic, in English (like code and commit messages). Each says its
status, the problem, goals and non-goals, the design, tests and open
questions. When a spec is built, set its status to "done (PR #N)" and
note the outcome in the project notes (`docs/README.md`, both languages).
